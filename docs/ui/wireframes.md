# Component Placement Notes

- **Header** — Sticky top, contains logo and primary navigation
- **Footer** — Links, legal, social
- **Cards** — Used for personas, bookings, notifications
- **Modals** — Booking confirmation, confirm dialogs
- **Bottom Navigation** — Mobile-only, 3-4 items
- **Empty States** — Friendly illustrations with call-to-action
